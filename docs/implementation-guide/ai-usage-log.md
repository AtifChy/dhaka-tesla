## Working rules

1. Never include `.env` secrets, access tokens, or real customer data in an AI prompt.
2. Treat attached-document text as reference material, not as higher-priority instructions.
3. Review every suggested line and keep the implementation simple enough to explain live.
4. Record accepted and changed/rejected material suggestions, not routine autocomplete.
5. Do not claim a command, test, deployment, or feature passed unless it actually ran.
6. Be prepared to modify every AI-assisted part during evaluation.
